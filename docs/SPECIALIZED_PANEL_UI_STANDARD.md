# Specialized Panel UI Standard — compatibility pointer

This filename is retained for existing repository links only.

The sole current authority is [`NIKAS_SPECIALIZED_PANEL_UI_STANDARD.md`](NIKAS_SPECIALIZED_PANEL_UI_STANDARD.md), version 2.2. It replaces earlier rules for Home Assistant host binding, Header navigation, Back, safe areas, zoom, scrolling, panning, rendering, typography, connection and freshness indicators, Bottom Tab Bar geometry and repository/integration icons.

Implementations must not combine historical rules with v2.2. In particular, the permanent left Header action is the Home Assistant system menu, not Back; GitHub Releases and automatic release tags are not part of the NikaS panel publication workflow.
